∞ Kreafinity OS

L'assistant système piloté par IA, où c'est vous qui choisissez votre IA.

Dernière version : @VERSION@ (@ARCH@)

Installer (Debian 12 et 13, Ubuntu 24.04 et dérivées)

Une commande : le paquet s'installe et ajoute ce dépôt, pour que les mises à jour arrivent ensuite avec celles du système.

curl -fsSLo /tmp/kreafinity.deb @URL@/kreafinity_latest_@ARCH@.deb
sudo apt install /tmp/kreafinity.deb

Ou en ajoutant d'abord le dépôt

sudo curl -fsSLo /usr/share/keyrings/kreafinity-archive-keyring.gpg @URL@/kreafinity-archive-keyring.gpg
sudo curl -fsSLo /etc/apt/sources.list.d/kreafinity.sources @URL@/kreafinity.sources
sudo apt update
sudo apt install kreafinity

Mettre à jour

Avec le reste du système : sudo apt update && sudo apt upgrade, ou la logithèque.

Retirer

sudo apt remove kreafinity (vos réglages et conversations restent dans votre dossier personnel ; kreafinity uninstall --purge avant, pour les effacer aussi).
